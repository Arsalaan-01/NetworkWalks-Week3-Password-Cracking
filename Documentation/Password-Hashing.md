# Password Hashing – Notes

A password hash is the output of a one-way cryptographic function.

## Hashing vs Encryption

- Hashing is designed to be one-way.
- Encryption is reversible using the appropriate key.

## Why Password Hashes Are Audited

Authorised password auditing checks whether passwords are weak or predictable.

## Defensive Lessons

- Use long, unique passwords.
- Use a password manager.
- Enable multi-factor authentication.
- Avoid password reuse.
