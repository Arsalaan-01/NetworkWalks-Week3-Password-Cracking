To understand password hash auditing using John the Ripper (JtR).

## Tools Used

- Johnny (Graphical Interface)
- PDF hash extraction utility

## Practical Workflow

1. Prepare the authorised lab PDF.
2. Extract its password hash using the specified utility.
3. Load the hash into John the Ripper.
4. Run the password audit using the lab instructions.
5. Analyse the output.
6. Verify any recovered password against the lab PDF.
